# 산나비 참고 게임 UI 콘셉트 검수 기록

## 주장
버튼 5종, 패널 2종, 챕터 카드, HUD 바 2종, 스킬 슬롯을 새로 생성하고 대시보드 기본 화면을 게임 메뉴 목업으로 바꿨다. 모든 자산은 `concept` 상태다.

## 증거
- 생성 명령: `node out/art-review-dashboard/game-ui-gen.mjs` → PNG 11장.
- `node --check`로 `game.js`, `game-ui-gen.mjs` 구문을 확인했다.
- `index.html`의 로컬 참조 34개가 모두 존재하고, PNG 11장의 디코딩·manifest 치수·비어 있지 않은 알파를 확인했다.
- 버튼, 챕터 카드, 패널, HUD 바 PNG를 개별 이미지로 확인했다.
- `node scripts/art-gate.mjs --out out/art-review-dashboard/art-gate`는 종료 코드 0이었지만, 설정된 기존 스프라이트 검사 1건만 실행했다. 이 UI 시안을 판정한 결과는 아니다.

## 기준
레퍼런스 UI의 측정 색(`#004646`, `#002929`, `#00ffff`)과 각진 모서리, 얇은 선, HUD 분절을 새 이미지로 재구성했다. 추출 게임 이미지의 픽셀은 복사하지 않았다.

## 공백
브라우저의 로컬 파일 접근이 자동화 보안 정책에 의해 차단되어 실제 HTML 렌더링은 자동 검수하지 못했다. 모바일 화면, UI 텍스트 오버플로, 색각이상, 엔진 삽입, FX 스타일 통일은 미검수다.

## 잔여 위험
9-slice 값은 제안 규격이며 엔진에서 늘려 보지 않았다. FX 4종은 이전 시안을 유지해 새 UI와 색·형태가 완전히 맞는지 사람의 판단이 필요하다.
