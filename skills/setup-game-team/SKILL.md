이 스킬은 현재 게임 프로젝트 레포 루트에 `CLAUDE.md`를 생성하여, 이 플러그인의 역할
에이전트들이 일관된 파이프라인과 사람 승인 게이트로 동작하도록 만든다.

## 절차

### 1. 프로젝트 파악
먼저 레포를 살핀다. 이미 코드가 있으면 스택을 추론한다.
- 파일 확장자/설정 파일로 엔진·언어 추정 (예: `*.unity`/`*.cs` → Unity, `project.godot`/`*.gd` → Godot,
  `*.uproject`/`*.cpp` → Unreal, `index.html`/`package.json` → 웹).
- 기존 `CLAUDE.md`가 있으면 덮어쓰지 말고 병합 여부를 사람에게 확인.

### 2. 빠진 정보만 질문
아래 중 코드에서 확인 불가능한 것만 사람에게 묻는다. 이미 알 수 있으면 묻지 말 것.
- 장르 / 프로젝트 한 줄 소개
- 엔진·언어·실행(빌드) 방법
- 유지해야 할 기존 자산/시스템(있다면)
- 프로젝트 고유 컨벤션(색 규칙, 네이밍 등)

### 3. CLAUDE.md 생성
`references/claude-md-template.md`를 읽어 템플릿을 뼈대로 삼고, 파악한 값으로 플레이스홀더를
채워 레포 루트에 `CLAUDE.md`로 쓴다. 규칙:
- 파이프라인 5단계와 사람 승인 게이트는 항상 포함(수정 금지 핵심).
- "밸런스 수치는 한 곳에 모은다" 원칙은 항상 포함.
- 추측으로 채운 값은 `<추정>`으로 표시하고, 사람 확인 항목으로 남긴다.

### 4. 확인 안내
생성 후 사람에게: (a) `.claude/agents/`에 이 플러그인의 5개 에이전트가 설치돼 있는지,
(b) 첫 실행은 plan 모드로 게이트를 눈으로 확인할 것을 안내한다.

## 참고
- 파이프라인/게이트/컨벤션 상세와 템플릿은 `references/claude-md-template.md` 참조.
