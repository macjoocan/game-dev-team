# game-dev-team

게임 개발용 **역할 에이전트 팀**과 **사람 승인 게이트 기반 파이프라인**을 어느 게임
프로젝트에서든 재사용하도록 묶은 플러그인. 목적은 **기획 → 게임성 검증 → 프로토타입**을
데이터 기반으로 굴리는 것. 최종 권위자는 항상 사람(당신)이다.

## 무엇이 들어있나

### 역할 에이전트 5개 (`agents/`)
| 에이전트 | 역할 |
|---|---|
| `pm` | 태스크 분해·우선순위·추적 |
| `game-designer` | 기획/밸런스 설계·검토, **게임성 지표 정의·검증**(게이트: 근거 없는 수치 0) |
| `developer` | 프로토(스파이크)·본구현·시뮬 하네스 (worktree 격리) |
| `qa` | **정확성** 검증·코드 리뷰·버그 리포트 (재미/밸런스는 담당 아님) |
| `artist` | 비주얼 시안·톤 관리 |

에이전트는 **허브-앤-스포크**로 동작한다. 서로 직접 대화하지 않고, 오케스트레이터(메인 세션)가
결과를 모아 다음 역할로 전달하며 각 단계는 사람 승인을 거친다.

### 스킬 2개 (`skills/`)
- **`setup-game-team`** — 새 게임 레포에 7단계 파이프라인이 담긴 `CLAUDE.md`를 스택 맞춤으로 생성.
- **`balance-sim`** — 전투/런을 수백~수천 번 자동 플레이해 승률·런 길이·픽률·사망 곡선을
  목표 지표와 대조하는 **게임성 검증** 스킬. "밸런스 시뮬 돌려줘"에 트리거.

## 파이프라인 (각 화살표 = 사람 승인 게이트)
```
① 기획+게임성지표(designer) → ② 태스크분해(pm) → ③ 프로토(스파이크, dev)
     → ④ 게임성 검증(designer+balance-sim) → ⑤ 본구현(dev) → ⑥ 정확성 QA(qa) → ⑦ 아트(artist)
```
- **③↔④는 반복 루프.** 시뮬 지표가 목표에 미달하면 ①(기획)으로 되돌려 재조정한다.
  재미가 나오기 전에는 ⑤ 본구현으로 넘어가지 않는다.
- **④(게임성 검증)와 ⑥(QA)는 다르다.** ④=재미/밸런스(데이터), ⑥=정확성(버그).

## 사용법
1. 이 플러그인을 설치한다.
2. 게임 레포에서 `게임 팀 세팅해줘` → `setup-game-team`이 `CLAUDE.md`를 생성.
3. 첫 실행은 plan 모드로 게이트를 눈으로 확인.
4. 게임성 검증: `밸런스 시뮬 1000판 돌려서 승률 뽑아줘`.

자세한 설치·사용법은 [USAGE.md](./USAGE.md) 참조.
