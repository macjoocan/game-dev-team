# game-dev-team

게임 개발용 **역할 에이전트 팀**과 **사람 승인 게이트 기반 파이프라인**을 어느 게임
프로젝트에서든 재사용하도록 묶은 플러그인. 목적은 **기획 → 게임성 검증 → 프로토타입**을
데이터 기반으로 굴리는 것. 최종 권위자는 항상 사람(당신)이다.

## 무엇이 들어있나

### 역할 에이전트 (`agents/`)
| 에이전트 | 역할 |
|---|---|
| `pm` | 태스크 분해·우선순위·추적 |
| `game-designer` | 기획/밸런스 설계·검토, 게임성 지표 정의·검증 |
| `developer` | 프로토·본구현·시뮬 하네스 (worktree 격리) |
| `qa` | **정확성** 검증·코드 리뷰·버그 리포트 |
| `artist` | 비주얼 시안·톤 관리 |
| `meta-economy-designer` | 성장 구조·수익화·리텐션 설계·경제 검증 (core 통과 후) |

에이전트는 **허브-앤-스포크**로 동작. 서로 직접 대화하지 않고 오케스트레이터(메인 세션)가
결과를 모아 다음 역할로 전달하며 각 단계는 사람 승인을 거친다.

### 스킬 (`skills/`)
- **`setup-game-team`** — 새 게임 레포에 파이프라인이 담긴 `CLAUDE.md`를 스택 맞춤으로 생성.
- **`balance-sim`** — 전투/런을 자동 플레이해 승률·픽률·사망곱선을 목표와 대조하는 **게임성 검증**.
- **`econ-sim`** — 성장/수익화/리텐션(가챠+광고+F2P)을 코호트 시뮬로 검증하는 **경제 검증**. core 재미 통과 후 사용.

## 파이프라인 (각 화살표 = 사람 승인 게이트)
```
① 기획+게임성지표(designer) → ② 태스크분해(pm) → ③ 프로토(dev)
     → ④ 게임성 검증(designer+balance-sim) → ⑤ 본구현(dev) → ⑥ 정확성 QA(qa) → ⑦ 아트(artist)
```
- **③↔④는 반복 루프.** 지표 미달 시 ①로 되돌려 재조정. 재미 전에는 ⑤로 안 넘어간다.
- 재미(④) 통과 후 **라이브 서비스 트랙**(⑧ 메타/수익화 설계 → ⑨ 경제 검증(econ-sim) → ⑩ 구현)이 이어진다.
- **④(게임성, 재미) ≠ ⑥(QA, 정확성) ≠ ⑨(경제, 지속가능·공정).**

## 사용법
1. 이 플러그인을 설치한다.
2. 게임 레포에서 `게임 팀 세팅해줘` → `setup-game-team`이 `CLAUDE.md`를 생성.
3. 첫 실행은 plan 모드로 게이트를 눈으로 확인.

자세한 설치·사용법은 [USAGE.md](./USAGE.md) 참조.
