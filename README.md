# game-dev-team

게임 개발용 **역할 에이전트 팀**과 **사람 승인 게이트 기반 파이프라인**을 어느 게임
프로젝트에서든 재사용하도록 묶은 플러그인. 최종 권위자는 항상 사람(당신)이다.

## 무엇이 들어있나

### 역할 에이전트 5개 (`agents/`)
| 에이전트 | 역할 |
|---|---|
| `pm` | 태스크 분해·우선순위·추적 |
| `game-designer` | 기획/밸런스 설계·검토 (게이트: 근거 없는 수치 0) |
| `developer` | 구현·리팩터링 (worktree 격리) |
| `qa` | 검증·코드 리뷰·버그 리포트 (통과/조건부/반려) |
| `artist` | 비주얼 시안·톤 관리 |

에이전트는 **허브-앤-스포크**로 동작한다. 서로 직접 대화하지 않고, 오케스트레이터(메인 세션)가
결과를 모아 다음 역할로 전달하며 각 단계는 사람 승인을 거친다.

### 스킬 1개 (`skills/`)
- **`setup-game-team`** — 새 게임 레포에 팀 파이프라인이 담긴 `CLAUDE.md`를 스택 맞춤으로 생성.
  "게임 팀 세팅해줘" 같은 요청에 트리거.

## 사용법

1. 이 플러그인을 설치한다.
2. 게임 레포에서 `setup-game-team` 스킬을 실행해 `CLAUDE.md`를 만든다
   (엔진·언어·컨벤션을 물어보고 채워줌).
3. 첫 실행은 plan 모드로 시작해 각 게이트를 눈으로 확인한다.
4. 예: `이 기획을 검토부터 구현까지 진행해줘. 각 게이트는 나한테 확인받고.`

## 권장 확장 (선택)
- 엔진 MCP(Unity/Unreal/Godot), Blender MCP(3D 아트), GitHub/Linear/Notion 커넥터를 붙이면
  개발·QA·아트 에이전트가 에디터·트래커를 직접 다룰 수 있다.

## 파이프라인
```
기획/밸런스(designer) → 태스크 분해(pm) → 구현(developer) → 검증(qa) → 아트(artist)
   각 화살표 = 사람 승인 게이트
```
